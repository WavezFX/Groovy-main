### 2.4 Voice — partial (works, duplicated, over the peak budget)
Two separate listening pipelines:
| | Page pipeline | Rust pipeline |
|---|---|---|
| Files | `src/voice/{controller,wake,vad,mic,call,call-state,sentences,speak,instant,livekit}.ts`, `island/voice.ts` | `okgroovy/{mod,wake,basic,brain}.rs`, `speech/{kws,audio,mod,cloud,tts,helper,mapped}.rs`, `voice.rs`, `calls.rs`, `livekit.rs`, `flow/*` (dictation) |
| Microphone | `getUserMedia` in the island WebView | `cpal` in `groovy.exe` |
| Wake phrases | "Groovy", "Hey Groovy", "Yo Groovy" (`voice/wake.ts`) | "OK Groovy", "Okay Groovy", "Hey Groovy", plus his name (`speech/kws.rs` `KEYWORDS`) |
| After the wake | chat question or a voice call | tool-calling command (`okgroovy/brain.rs`) |
- **STT:** cloud first when a key exists (`speech/cloud.rs`: Deepgram, OpenAI, ElevenLabs, Gemini), else Whisper base (default) or Parakeet (opt-in), both in the `stt` helper.
- **TTS:** Fish Audio → Kokoro (`tts` helper) → ElevenLabs / Windows voices in the page.
- **Live calls:** normal pipeline (speech → AI → voice), "Instant voice" (OpenAI Realtime over WebRTC, Gemini Live over WebSocket; keys stay in Rust), or LiveKit (`livekit-client`, lazy import; token minted in `livekit.rs`).
- **Broken / open:** peak 331 MB against 300 (3N item 2). End-of-speech detection never benchmarked (3J item 2).

### 2.5 AI providers — partial (works, two dispatchers, no single interface)
- **Files:** `chat.rs` (`send` → `send_to`, chat window), `assistant.rs` (`AssistantPrefs`, `route`, `worth_falling_back`), `brain_ai.rs` (`Who`, `order`, `arrange`, `complete`, `tool_turn`, `CloudTally`, `is_limit`), adapters `claude.rs`, `openai_compat.rs` (google, openai, openrouter), `local_chat.rs` + `ollama.rs` + `models.rs` (Ollama, LM Studio, built-in llama.cpp, custom), `codex_plan.rs` (limits), `phone_link/chat_backend.rs`, `secrets.rs` (OS keychain); page `settings/brains.ts`, `settings/models.ts`, `island/brain.ts`.
- **Does:** cloud and subscription first, local last; limit-based switching; model per job (chat, writing, commands); router-plugin row in Settings, disabled.
- **Gaps:** there is **no `Brain` trait in Rust**: `chat.rs` and `brain_ai.rs` each dispatch by string or enum. Subscriptions are reached by shelling out to the `claude` and `codex` CLIs, text only (no tools, no streaming). **Gemini has no account sign-in path** (key only). `CLAUDE_FAST` is pinned to `claude-haiku-4-5`.

## 3. Risks
1. **Peak memory 331 MB (limit 300).** Kokoro's helper 171 MB, the island's WebView2 about 121 MB in a call (a call adds about 70 MB), `groovy.exe` about 39 MB. The work test peaks at 446 MB and does not gate.
2. **Idle is only met in Standby.** 105–115 MB with the island alone; Settings left open adds about 78 MB, which is over 150. No CI gate covers that state.
3. **Two microphone pipelines** with different wake phrases (2.4). Double CPU and memory when both are on, and "Yo Groovy" works in one, "OK Groovy" in the other.
4. **Animation engine ported from Coucou's Mochi** (2.2), and internal `mochi` names in 45 files. Legal exposure before anything is sold.
5. **Licence statement mismatch:** the repo is Apache-2.0 since 4 Nov 2026 (`LICENSE`, `/docs/LICENSING.md`), not GPL v2. `phone_link/mod.rs` points to `android/LICENSE`, which is not in the repo.
6. **Provider logic in two places** (2.5): a fix to switching in one path is missed in the other.
7. **Subscription brains have no tools:** on a Claude Code or Codex sign-in, « OK Groovy » commands answer in text only (`brain_ai.rs` `as_prompt`).
8. **Large single files:** `island.ts` 1728, `lib.rs` 1885, `settings/main.ts` 1591, `spotify.rs` 2245 lines. Costly for a Sonnet session to edit; read by range.
9. **`worktest.rs`** is test-only; a check keeps it out of the shipped exe. Keep that check.
10. **Model licences:** Parakeet is CC-BY-4.0 (credit required). Listed in `docs/licenses/MODELS.md`; confirm the credit ships in the installer.
