# Vercel `skills` CLI

Groovy's Skills Manager (`src-tauri/src/skills/`) runs Vercel's open-source
`skills` CLI, pinned to version 1.7.2, with `npx -y skills@1.7.2` and
`DISABLE_TELEMETRY=1`. Groovy does not bundle or modify the CLI; npm downloads
it on first use. Its licence (MIT, © Vercel, Inc.) and third-party notices are
kept here as required.
